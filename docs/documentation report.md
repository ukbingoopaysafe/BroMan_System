# برومان العقارية

## إدارة تكنولوجيا المعلومات

**التاريخ:** 30 / 11 / 2025

# توثيق مشروع نظام برومان العقارية

---

## 1. المقدمة

نظام **برومان العقارية (System BroMan)** هو تطبيق ويب داخلي متكامل تم تطويره خصيصًا لشركة **BroMan Real Estate**. يهدف هذا النظام إلى أتمتة وتبسيط العمليات الأساسية لإدارة العقارات، مما يضمن كفاءة عالية ودقة في سير العمل داخل الشركة.

تم تصميم النظام للعمل على **خادم محلي (Local Server)** ضمن شبكة الشركة، مما يوفر أمانًا عاليًا وتحكمًا كاملاً في البيانات الحساسة، إضافة إلى وصول سريع للمستخدمين المصرح لهم.

---

## 1.1 الغرض من الوثيقة

تهدف هذه الوثيقة إلى تقديم توثيق شامل للنظام، يشمل:

* البنية التقنية
* الميزات الأساسية والمتقدمة
* الأدوار والصلاحيات
* متطلبات التشغيل

وهي تعد مرجعًا رسميًا للفريق التقني والإدارة العليا.

# 2. البنية التقنية ومتطلبات التشغيل

## 2.1 Technology Stack

| المكون               | التقنية                 | الوصف                                       |
| -------------------- | ----------------------- | ------------------------------------------- |
| **لغة البرمجة**      | PHP                     | المنطق الخلفي للتطبيق                       |
| **قاعدة البيانات**   | MariaDB / MySQL         | تخزين بيانات العقارات والعملاء والمستخدمين  |
| **الواجهة الأمامية** | HTML5, CSS3, JavaScript | تصميم واجهة تفاعلية ومتجاوبة                |
| **إدارة الحزم**      | Composer                | إدارة المكتبات مثل phpoffice/phpspreadsheet |

---

## 2.2 متطلبات الخادم

لتشغيل النظام يجب توفر:

* خادم ويب **Apache أو Nginx**
* إصدار PHP **7.4 أو أعلى**
* تفعيل إضافات PHP التالية:

  * mysqli
  * session
  * mbstring
* قاعدة بيانات **MySQL أو MariaDB**

# 3. الميزات الرئيسية للنظام

يمثل هذا القسم توثيقًا شاملاً للميزات التي تمت إضافتها منذ بداية مشروع نظام برومان العقارية وحتى الإصدار الحالي.

---

## 3.1 إدارة المستخدمين والصلاحيات

| الميزة                   | الوصف                                                |
| ------------------------ | ---------------------------------------------------- |
| الهيكل الأولي للمشروع    | إنشاء المشروع وتضمين التصميم الأساسي لواجهة العقارات |
| إدارة الأدوار والصلاحيات | تغيير الأدوار إلى: Admin – Manager – User            |
| تقييد حذف العقارات       | الحذف مسموح فقط للمستخدمين من نوع **Manager**        |
| إدارة الموظفين           | إضافة إمكانية إنشاء موظفين بناءً على الدور           |
| تتبع نشاط المستخدم       | تسجيل ومراجعة جميع الأنشطة لأغراض التدقيق والأمان    |

---

| الميزة                        | الوصف                                                                    |

# 4. الخلاصة وإجراءات استدامة المشروع

يمثل نظام برومان العقارية أداة رئيسية لرقمنة عمليات الشركة، وقد مر بمراحل تطوير عديدة شملت:

* إدارة الأدوار
* تحسين الأمان
* تطوير واجهات المستخدم
* دعم الوسائط الخرائط
* مراجعة التكرارات

### إجراءات الاستدامة:

1. **نسخ احتياطي يومي** لقاعدة البيانات والملفات
2. **تحديثات أمنية منتظمة** لإصدارات PHP وقواعد البيانات
3. **التوسع المستقبلي** بإضافة ميزات جديدة بشكل دوري
