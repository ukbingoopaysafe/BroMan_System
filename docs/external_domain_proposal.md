## إدارة تكنولوجيا المعلومات

**التاريخ:** 11 / 12 / 2025

# مقترح تشغيل النظام عبر دومين خارجي
## طلب الموافقة على النشر الخارجي

---

## 1. المقدمة

يهدف هذا المقترح إلى عرض خطة لتوسيع نطاق الوصول لـ **نظام برومان العقارية** ليصبح متاحاً للموظفين من أي مكان عبر الإنترنت، مع الحفاظ على أعلى معايير الأمان والخصوصية.

---

## 2. الوضع الحالي

| البند | الوصف |
|-------|-------|
| **بيئة التشغيل** | خادم محلي (Local Server) داخل شبكة الشركة |
| **طريقة الوصول** | عبر الشبكة الداخلية فقط (broman.local) |
| **القيود** | الموظفون خارج المكتب لا يستطيعون الوصول للنظام |

---

## 3. المقترح

### 3.1 الهدف

تمكين الموظفين من الوصول للنظام من أي مكان عبر **دومين خارجي آمن**، مما يتيح:

- العمل عن بُعد
- الوصول أثناء الزيارات الميدانية للعقارات
- المرونة في ساعات العمل

### 3.2 الحل التقني: Cloudflare Tunnel

| البند | التفاصيل |
|-------|----------|
| **التقنية** | Cloudflare Tunnel (نفق آمن مشفر) |
| **المميزات** | لا يتطلب فتح منافذ في الراوتر، IP السيرفر مخفي |
| **الأمان** | حماية DDoS، جدار حماية تطبيقات الويب، شهادة SSL مجانية |
| **التكلفة** | مجاني بالكامل |

### 3.3 كيف يعمل؟

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   الموظف (أي مكان)  ──►  Cloudflare  ──►  Tunnel  ──►  السيرفر │
│        ☁️                  🛡️              🔒           🖥️      │
│                                                                 │
│   • اتصال HTTPS مشفر                                           │
│   • حماية DDoS                                                  │
│   • IP السيرفر مخفي تماماً                                     │
│   • لا حاجة لفتح بورتات                                        │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 4. الدومين المقترح

### 4.1 عرض Hostinger المجاني

> ✅ **متوفر لدينا:** دومين مجاني لمدة سنة كاملة من Hostinger جاهز للاستخدام

### 4.2 مقترحات أسماء الدومين

نرجو من الإدارة اختيار اسم الدومين المناسب من الاقتراحات التالية:

| الاقتراح | الوصف |
|----------|-------|
| `broman.com` | الاسم الرئيسي للشركة (قد لا يكون متاحاً) |
| `broman-re.com` | برومان للعقارات (Real Estate) |
| `bromaneg.com` | برومان مصر |
| `broman-system.com` | نظام برومان |
| `broman-properties.com` | عقارات برومان |
| `mybroman.com` | بوابة برومان |

> **ملاحظة:** يمكن التحقق من توفر أي اسم عبر موقع Hostinger قبل الاختيار النهائي.

---

## 5. إجراءات الأمان المُطبّقة

تم تجهيز النظام بطبقات حماية متعددة قبل النشر الخارجي:

| الطبقة | الإجراء | الحالة |
|--------|---------|--------|
| **1** | Rate Limiting (حظر المحاولات المتكررة) | ✅ جاهز |
| **2** | CSRF Protection (حماية ضد الهجمات) | ✅ جاهز |
| **3** | Security Headers (رؤوس أمان HTTP) | ✅ جاهز |
| **4** | حماية ملفات النظام الحساسة | ✅ جاهز |
| **5** | تشفير HTTPS عبر Cloudflare | ✅ جاهز |
| **6** | حماية DDoS عبر Cloudflare | ✅ جاهز |
| **7** | إخفاء IP السيرفر الحقيقي | ✅ جاهز |

### تفاصيل حماية Rate Limiting

- حظر الـ IP بعد **5 محاولات دخول فاشلة** لمدة 15 دقيقة
- حظر الحساب بعد **10 محاولات فاشلة** لمدة 30 دقيقة
- تسجيل جميع المحاولات للمراقبة

## 6. التكلفة والميزانية

| البند | التكلفة |
|-------|---------|
| **الدومين** | مجاني (لمدة سنة) - عرض Hostinger |

| **شهادة SSL** | مجانية (من Cloudflare) |
| **الإجمالي** | **صفر** |

## 7. الفوائد المتوقعة

| الفائدة | الوصف |
|---------|-------|
| **مرونة العمل** | الموظفون يستطيعون العمل من أي مكان |
| **الإنتاجية** | الوصول للبيانات أثناء الزيارات الميدانية |
| **الاستمرارية** | عدم توقف العمل في حالات الطوارئ |
| **التوسع** | إمكانية إضافة مستخدمين خارجيين مستقبلاً |
| **الصورة المهنية** | دومين خاص يعكس احترافية الشركة |

---

## 8. المخاطر والتخفيف

| المخطر | الاحتمال | التخفيف |
|--------|----------|---------|
| محاولات اختراق | متوسط | Rate Limiting + Cloudflare WAF |
| انقطاع الإنترنت | منخفض | السيرفر المحلي يظل يعمل محلياً |
| فقدان البيانات | منخفض جداً | نسخ احتياطي يومي |

---

## 9. خطة التنفيذ

| المرحلة | المهمة | المدة |
|---------|--------|-------|
| **1** | اختيار وحجز الدومين | يوم واحد |

| **5** | إطلاق تجريبي (موظفين محددين) | أسبوع |

3. **تحديد الموظفين** للمرحلة التجريبية

---

## 11. الخلاصة

يمثل هذا المقترح خطوة استراتيجية لتحديث البنية التحتية التقنية للشركة، مع:

- **تكلفة صفرية** للسنة الأولى
- **أعلى معايير الأمان**
- **مرونة غير مسبوقة** للموظفين
- **تنفيذ سريع** خلال أيام

نوصي بالموافقة على المقترح والبدء في التنفيذ في أقرب وقت ممكن للاستفادة من عرض الدومين المجاني.
