# تحديث نظام الأدوار - Broman Real Estate System

## نظرة عامة
تم تحديث نظام إدارة العقارات ليشمل ثلاثة أدوار بدلاً من اثنين:

### الأدوار الجديدة:
1. **مدير (Manager)** - جميع الصلاحيات
2. **مسؤول (Admin)** - إدارة العقارات فقط
3. **مستخدم (User)** - عرض العقارات فقط

## الصلاحيات التفصيلية:

### مدير (Manager):
- ✅ إدارة الموظفين (إضافة، تعديل، حذف)
- ✅ إدارة العقارات (إضافة، تعديل، حذف)
- ✅ عرض جميع الإحصائيات
- ✅ الوصول لجميع أجزاء النظام

### مسؤول (Admin):
- ❌ إدارة الموظفين
- ✅ إدارة العقارات (إضافة، تعديل، حذف)
- ✅ عرض إحصائيات العقارات
- ❌ عرض إحصائيات الموظفين

### مستخدم (User):
- ❌ إدارة الموظفين
- ❌ إدارة العقارات
- ✅ عرض العقارات فقط
- ✅ عرض إحصائيات العقارات

## التغييرات المطبقة:

### 1. قاعدة البيانات:
- تم تحديث جدول `employees` لإضافة دور `manager`
- تم إضافة مستخدم مدير تجريبي:
  - اسم المستخدم: `manager`
  - كلمة المرور: `manager123`

### 2. الملفات الجديدة:
- `permissions.php` - نظام إدارة الصلاحيات الجديد
- `update_roles.sql` - سكريبت تحديث قاعدة البيانات

### 3. الملفات المحدثة:
- `broman_db.sql` - تحديث بنية قاعدة البيانات
- `navbar.php` - تحديث القائمة حسب الصلاحيات
- `dashboard.php` - تحديث عرض الإحصائيات
- جميع صفحات إدارة العقارات
- جميع صفحات إدارة الموظفين
- جميع صفحات عرض العقارات

## كيفية التطبيق:

### الطريقة الأولى - قاعدة بيانات جديدة:
1. إنشاء قاعدة بيانات جديدة
2. استيراد ملف `broman_db.sql` المحدث
3. رفع الملفات إلى الخادم

### الطريقة الثانية - تحديث قاعدة بيانات موجودة:
1. تشغيل سكريبت `update_roles.sql` على قاعدة البيانات الحالية
2. رفع الملفات المحدثة إلى الخادم

## الميزات الجديدة:

### 1. نظام صلاحيات محسن:
- فحص تلقائي للصلاحيات في كل صفحة
- رسائل خطأ واضحة عند عدم وجود صلاحية
- إعادة توجيه تلقائية للصفحات المناسبة

### 2. واجهة مستخدم محدثة:
- إخفاء/إظهار القوائم حسب الصلاحيات
- إخفاء/إظهار أزرار التعديل والحذف
- عرض الإحصائيات حسب الصلاحيات

### 3. أمان محسن:
- فحص الصلاحيات على مستوى الخادم
- حماية من الوصول المباشر للصفحات
- تسجيل الأخطاء والمحاولات غير المصرح بها

## ملاحظات مهمة:

1. **النسخ الاحتياطي**: تأكد من أخذ نسخة احتياطية من قاعدة البيانات والملفات قبل التطبيق
2. **اختبار الصلاحيات**: اختبر جميع الأدوار للتأكد من عمل الصلاحيات بشكل صحيح
3. **كلمات المرور**: غيّر كلمات المرور الافتراضية بعد التطبيق
4. **الترجمة**: النظام يدعم العربية والإنجليزية

## الدعم الفني:
في حالة وجود أي مشاكل أو استفسارات، يرجى التواصل مع فريق التطوير.
